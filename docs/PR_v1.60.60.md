## Every new flag defaults OFF
| BotConfig field | default | effect when ON |
|---|---|---|
| `gold_bias_gtp_direction_enabled` | false | gold_trend_pulse enters only in the Gold Daily Bias direction |
| `gold_bias_block_counter_enabled` | false | hf_scalp / hf_scalp_fast / breakout_m15 entries against a STRONG bias (|score| ≥ 60) are skipped |
| `exit_policy` | `fixed_tp` | `tp1_bank_runner`: bank at TP1, SL → entry ± offset, runner trails to TP2 |
| `tp1_close_fraction` / `be_plus_offset_price` / `tp2_multiple` | 0.5 / 1.0 / 2.0 | parameters of the policy |

No change to entry gates, guards, freezes, the macro gate or position sizing. With the defaults the only new runtime
behaviour is: a 15-min read-only bias refresh + shadow logging of gold signals + calendar outcome recording.
