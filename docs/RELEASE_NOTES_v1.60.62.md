# v1.60.62 — two display fixes (#82 GTP news line date · #83 Exit Rule Scoreboard broker SL/TP)

No trading logic, config, flags or `requirements.txt` changes. Protected paths untouched; artifacts regenerated by script.

## #82 GTP card news line shows the date when the event is not today
`rules_news_sweep.news_plan_text(event, kind, release_min, now)` formats `%H:%M` only for an event on today's UTC date;
otherwise it prefixes weekday + date: **"FOMC Wed 28 Oct 18:00 UTC — protect at 17:45, news trades from 18:05"** (was
"FOMC 18:00 UTC …" on the Saturday before, reading like an event due in hours). `next_news_event` passes its `now`.
Tests: not-today / same-day / near-midnight UTC.

## #83 Exit Rule Scoreboard classifies real broker SL/TP fills
`scalp.reports.summarise` counted SL/TP in the "closed without either rule" line only by `close_reason` prefix `stop` /
`take_profit`; real broker fills arrive as `broker_confirmed` / `broker_reconciled_estimated+external_close` /
`external_close` (the EA deal payload carries no deal reason), so 10 broker stop fills (13–16 Oct, −$115.74) showed as
"0 SL / 0 TP". New `broker_exit_kind(trade)`: explicit bot reasons first; otherwise the exit price against the stop /
target live at the close (current level first — a stop moved to breakeven counts — original as fallback) within a
tolerance of 15 % of the original stop distance, minimum 3 pips; an exit beyond the stop in the losing direction (gap)
is a stop fill; mid-way manual closes and trades without an exit price stay "neither". The scoreboard query now
projects `exit_price`, `stop_loss`, `take_profit`, `original_stop_loss`, `original_take_profit`.
Tests: both close_reason forms, slippage, gap-through, SELL side, breakeven-moved stop, FX pips, 10-fill scoreboard.
