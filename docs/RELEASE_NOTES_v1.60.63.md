# v1.60.63 — #85 Trade cost ledger + smart spread gate (SHADOW first)

Gold priority, per symbol by design. **No change to order sending or exit rules while `spread_gate_mode = shadow`
(the default on every account).** No change to existing `max_spread_pips` values. `requirements.txt` untouched; protected
paths untouched; artifacts regenerated by script. New module `backend/trade_costs.py`.

Why: entry costs already existed (`spread_at_entry_pips`, `slippage_pips`, `commission_pips`) but the static spread filter
(XAUUSD default 50 pips = $5.00) never fires against $2–4.50 targets, and nothing measured the exit side. Costs are
≈ 0.04–0.10 R per trade — the size of the scalpers' gross edge — so they are now measured and gated **per broker**.

## A) Cost ledger (every trade, every account)
1. **Exit costs on close** (`stamp_exit_costs`, from the authoritative broker OUT deal in `bridge_routes.external_deal`,
   fail-soft, idempotent): `exit_slippage_pips` = signed broker close price vs the level that triggered it (SL or TP live at
   close — a BE-moved stop counts; kind via `scalp.reports.broker_exit_kind`, gap-through = stop), **positive = worse**;
   `exit_kind`; `exit_spread_pips` from the latest heartbeat.
2. **`cost_summary`** on the trade: `pips` / `usd` for spread_entry, slip_entry, slip_exit, commission (round trip);
   `total_cost_pips`, `total_cost_usd`, `total_cost_R` (vs the **ORIGINAL** stop distance), `cost_pct_of_tp` (vs the
   **ORIGINAL** TP distance), `missing` inputs (count 0, listed), per-symbol `pip_size` / `pip_usd_per_lot`.
3. **Spread history**: heartbeat spread samples per account + base symbol, aggregated per UTC hour of day in a
   `(account, symbol, day)` doc (≤ 60 samples/hour/day), rolling 14 days via TTL `expires_at`; `hour_stats` → median, p90, n;
   `session_spreads` → Asia 0–7 / London 7–13 / NY 13–21 / late 21–24 UTC. Fail-soft from the heartbeat.
4. **Report**: Bot Health → **"Trading costs · spread gate"** card (`TradingCostsCard`) and `GET /api/diagnostic/trade-costs?days=7`
   (own data): per broker — spread by session, avg entry & exit slippage, avg total cost in R and % of TP, total $, worst 5 trades
   by cost; the same block is the `trading_costs` section of `/api/insights/weekly-digest` (daily report with `days=1`).

## B) Smart spread gate (SHADOW by default)
5. BotConfig (audited path, Bot Config → Trading Intelligence → "Smart spread gate"): `spread_gate_mode` **"shadow"** |
   "off" | "enforce"; `spread_gate_mult` 1.5; `max_cost_pct_of_tp` 12.
6. In `bot_runner`, after every existing filter (spread filter, EV, quality, execution alpha/timing) and right before
   dispatch, all engines incl. gold_trend_pulse: block when (a) current spread > mult × **this account's median spread for
   this UTC hour** (needs n ≥ 30 samples in 14 days, else the static `max_spread_pips` cap), or (b) expected round-trip cost
   (spread + this account's median entry slippage + commission pips) > `max_cost_pct_of_tp` % of the planned TP distance.
   **shadow**: never blocks — `signal.spread_gate = {would_block, reason, rule, spread, median, n, cost_pct, basis, mode…}`
   is stamped and `spread_gate_shadow` counted; **enforce**: SKIP with pulse *"Spread gate — XAUUSD spread 4.1p > 1.5× hour
   median 2.4p"* (or the cost-% / static-cap wording). Fail-open on any error.
7. **Shadow scoreboard** (card + endpoint): executed trades the gate WOULD have blocked vs the ones that passed — count,
   win rate, net R / $, and which rule fired — to judge the gate before enforcing. The verdict travels with the trade.
8. Static cap shown in **$ as well as pips** in Bot Config ("50 pips = $5.00 per oz") — values unchanged.
